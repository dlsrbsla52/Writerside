#### 1. 아래 자바 코드에서 출력되는 값을 작성하시오.


```java
class Static{
    public int a = 20;
    static int b = 0;
}

public class Main{

    public static void main(String[] args) {
        int a;
        a = 10;
        Static.b = a;
        Static st = new Static();
        System.out.println(Static.b++);
        System.out.println(st.b);
        System.out.println(a);
        System.out.print(st.a);
    }
}
```



- 정답 및 해설
  - 정답 :
	```
	10
	11
	10
	20
	```
  - 해설 :
	주어진 자바 코드에서 각 변수의 값을 추적해 보겠습니다.
	
	### 코드 분석:
	
	1. **클래스 정의 (`Static` 클래스)**:
	   ```java
	   class Static {
	       public int a = 20;
	       static int b = 0;
	   }
	   ```
	   - `Static` 클래스에는 두 개의 필드가 있습니다:
	     - `int a = 20;`: 인스턴스 변수로, 각 객체마다 고유한 값을 가집니다.
	     - `static int b = 0;`: 클래스 변수로, **모든 객체가 공유**하는 변수입니다.
	
	2. **`Main` 클래스에서 `main()` 메소드**:
	   ```java
	   public static void main(String[] args) {
	       int a;
	       a = 10;
	       Static.b = a;
	       Static st = new Static();
	       System.out.println(Static.b++);
	       System.out.println(st.b);
	       System.out.println(a);
	       System.out.print(st.a);
	   }
	   ```
	   - `int a;`와 `a = 10;`은 **지역 변수 `a`를 선언**하고 값을 할당합니다. `a = 10`입니다.
	   - `Static.b = a;`는 `Static` 클래스의 정적 변수 `b`에 지역 변수 `a`의 값을 대입합니다. 즉, `b = 10`이 됩니다.
	   - `Static st = new Static();`는 `Static` 클래스의 객체 `st`를 생성합니다.
	   - **출력문 분석**:
	     1. **`System.out.println(Static.b++);`**:
	        - 현재 `Static.b`는 `10`입니다.
	        - 출력 후에 후위 증가 연산자 `++`가 적용되므로, 출력되는 값은 `10`이고 `Static.b`는 `11`로 증가합니다.
	     2. **`System.out.println(st.b);`**:
	        - `Static.b`는 정적 변수로 모든 객체에서 공유됩니다.
	        - 이전 출력문에서 `b`의 값이 `11`로 증가했으므로, 이 줄에서 출력되는 값은 **`11`**입니다.
	     3. **`System.out.println(a);`**:
	        - 지역 변수 `a`의 값은 **`10`**이므로 출력값은 **`10`**입니다.
	     4. **`System.out.print(st.a);`**:
	        - `st` 객체의 인스턴스 변수 `a`는 **`20`**으로 초기화되어 있습니다. 따라서 출력값은 **`20`**입니다.
	
	### 최종 출력:
	
	```
	10
	11
	10
	20
	```
	
	- **`System.out.println(Static.b++);`**: `10` (후위 증가, 출력 후 `b`는 `11`이 됨)
	- **`System.out.println(st.b);`**: `11` (정적 변수 `b`는 `11`)
	- **`System.out.println(a);`**: `10` (지역 변수 `a`는 `10`)
	- **`System.out.print(st.a);`**: `20` (인스턴스 변수 `a`는 `20`)









#### 2. 다음 C언어의 출력값을 작성하시오.

```C
#include <stdio.h>

int main(){  
    char a[] = "Art";
    char* p = NULL;
    p = a;
    printf("%s\n", a);
    printf("%c\n", *p);
    printf("%c\n", *a);
    printf("%s\n", p);
    for(int i = 0; a[i] != '\0'; i++)
    printf("%c", a[i]);
}
```



- 정답 및 해설
  - 정답 :
	```
	Art
	A
	A
	Art
	Art
	```
  - 해설
	주어진 C 코드에서 각 출력문의 결과를 분석해 보겠습니다.
	
	### 코드 분석:
	
	```c
	#include <stdio.h> 
	
	int main() {  
	    char a[] = "Art";
	    char* p = NULL;
	    p = a;
	    printf("%s\n", a);
	    printf("%c\n", *p);
	    printf("%c\n", *a);
	    printf("%s\n", p);
	    for(int i = 0; a[i] != '\0'; i++)
	        printf("%c", a[i]);
	}
	```
	
	#### 각 변수와 코드 동작 설명:
	
	1. **변수 초기화**:
	   - **`char a[] = "Art";`**:
	     - 문자열 `"Art"`를 배열 `a`에 저장합니다.
	     - 배열 `a`는 `{'A', 'r', 't', '\0'}`로 구성됩니다. 문자열 끝에는 **널 문자 `'\0'`**이 자동으로 추가됩니다.
	
	   - **`char* p = NULL;`**:
	     - 포인터 `p`를 **NULL**로 초기화합니다.
	
	   - **`p = a;`**:
	     - 포인터 `p`는 이제 배열 `a`를 가리킵니다.
	     - 즉, `p`는 `a`의 첫 번째 요소인 문자 `'A'`의 주소를 가리킵니다.
	
	2. **출력문 분석**:
	
	   1. **`printf("%s\n", a);`**:
	      - `%s`는 문자열 형식 지정자이며, 배열 `a`의 문자열 전체를 출력합니다.
	      - **출력**: `"Art"`
	
	   2. **`printf("%c\n", *p);`**:
	      - `%c`는 문자 형식 지정자이며, 포인터 `p`가 가리키는 값을 출력합니다.
	      - `p`는 `a`의 첫 번째 요소를 가리키므로, `*p`는 **`'A'`**입니다.
	      - **출력**: `'A'`
	
	   3. **`printf("%c\n", *a);`**:
	      - `%c`는 문자 형식 지정자이며, 배열 `a`의 첫 번째 요소를 출력합니다.
	      - `*a`는 배열 `a`의 첫 번째 요소인 **`'A'`**를 나타냅니다.
	      - **출력**: `'A'`
	
	   4. **`printf("%s\n", p);`**:
	      - `%s`는 문자열 형식 지정자이며, 포인터 `p`가 가리키는 문자열 전체를 출력합니다.
	      - `p`는 배열 `a`의 시작 주소를 가리키므로, **`"Art"`**가 출력됩니다.
	      - **출력**: `"Art"`
	
	   5. **`for(int i = 0; a[i] != '\0'; i++) printf("%c", a[i]);`**:
	      - `for` 루프는 배열 `a`의 각 요소를 **널 문자 `'\0'`**이 나올 때까지 하나씩 출력합니다.
	      - 배열 `a`의 요소는 `{'A', 'r', 't', '\0'}`입니다.
	      - 따라서 **`'A'`, `'r'`, `'t'`**가 출력됩니다.
	      - **출력**: `"Art"`
	
	### 최종 출력:
	
	```
	Art
	A
	A
	Art
	Art
	```
	
	각 출력문은 배열과 포인터의 사용을 통해 문자열과 개별 문자를 정확히 출력합니다.









#### 3. 다음 C언어의 출력값을 작성하시오.

```C
#include <stdio.h>

int main(){
    char* a = "qwer";
    char* b = "qwtety";

    for(int i = 0; a[i] != '\0' ; i++){
        for(int j = 0; b[j] != '\0'; j++){
            if(a[i] == b[j]) printf("%c", a[i]);
        }
    }
}
```



- 정답 및 해설
  - 정답 : `qwe`
  - 해설 
	
	- **문자열 `a`**: `"qwer"`
	- **문자열 `b`**: `"qwtety"`
	
	코드는 문자열 `a`의 각 문자와 문자열 `b`의 모든 문자를 **비교**하여 같은 문자가 있을 경우 출력합니다.
	
	#### 출력 과정 상세 분석:
	
	1. **`i = 0`, `a[i] = 'q'`**:
	   - `j = 0`, `b[j] = 'q'`: **일치**. 출력: `'q'`
	   - 이후 `j = 1`부터 `b[j]` 값은 모두 `'q'`와 **다르므로** 더 이상 출력하지 않음.
	
	2. **`i = 1`, `a[i] = 'w'`**:
	   - `j = 1`, `b[j] = 'w'`: **일치**. 출력: `'w'`
	   - 이후 `j`가 2부터 시작하여 나머지 문자들도 모두 **다르므로** 더 이상 출력하지 않음.
	
	3. **`i = 2`, `a[i] = 'e'`**:
	   - `j = 3`, `b[j] = 'e'`: **일치**. 출력: `'e'`
	   - 이후 나머지 문자는 모두 **다르므로** 더 이상 출력하지 않음.
	
	4. **`i = 3`, `a[i] = 'r'`**:
	   - `b`에서 `'r'`에 해당하는 문자는 없습니다. 모든 문자는 **일치하지 않음**.
	
	### 최종 출력값:
	
	```
	qwe
	```
	
	- 문자열 `a`와 `b`에서 **공통으로 등장하는 문자**는 `'q'`, `'w'`, `'e'`입니다.
	- 따라서 최종 출력값은 **`qwe`**입니다.
	








#### 4. 다음 괄호안에 들어가는 용어의 Full Name 또는 약자를 작성하시오.


(   )은/는 비동기적인 웹 애플리케이션의 제작을 위해 JavaScript와 XML을 이용한 비동기적 정보 교환 기법이다.  
  
(   )은/는 필요한 데이터만을 웹서버에 요청해서 받은 후 클라이언트에서 데이터에 대한 처리를 할 수 있다.   
보통 SOAP이나 XML 기반의 웹 서비스 프로토콜이 사용되며, 웹 서버의 응답을 처리하기 위해 클라이언트 쪽에서는 자바스크립트를 쓴다.  
  
(   )은/는 Google Map과 Google pages에서 사용한 기술에 기반하여 제작되었다.


- 정답 및 해설
  - 정답 : ajax
  - 해설 : 
	주어진 설명은 **비동기 웹 애플리케이션**을 제작하기 위한 기술로, **JavaScript와 XML**을 이용해 서버와 정보를 비동기적으로 교환하는 기법을 설명하고 있습니다. 이 설명에 해당하는 용어는 **AJAX**입니다.
	
	### AJAX에 대한 설명:
	
	1. **AJAX (Asynchronous JavaScript and XML)**:
	   - **비동기적인 웹 애플리케이션 제작**을 위해 사용되는 기법입니다.
	   - **AJAX**는 **JavaScript와 XML**을 사용하여 클라이언트와 서버 간에 **비동기적**으로 데이터를 주고받습니다.
	   - 웹 페이지의 전체를 다시 로드하지 않고, 필요한 데이터만을 서버에 요청하여 받아오는 방식입니다.
	   - 이를 통해 **더 빠른 응답 시간**과 **향상된 사용자 경험**을 제공합니다.
	
	2. **기술 구성 요소**:
	   - **JavaScript**: 클라이언트 측에서 서버와 비동기적으로 통신하기 위해 사용합니다.
	   - **XMLHttpRequest 객체**: 서버와 통신을 하기 위해 JavaScript에서 사용되는 객체입니다.
	   - **XML 또는 JSON**: 서버로부터 데이터를 주고받을 때 사용되는 형식입니다. 원래 XML을 주로 사용했지만, 현재는 **JSON**이 더 많이 사용됩니다.
	
	3. **사용 예**:
	   - **Google Map**과 **Google pages** 등에서는 **AJAX**를 사용하여 사용자가 지도를 스크롤하거나 확대할 때마다 서버와 비동기적으로 통신하여 데이터를 가져와 사용자에게 제공합니다. 이를 통해 더 빠르고 원활한 사용자 경험을 제공합니다.
	
	### 요약:
	
	- **AJAX (Asynchronous JavaScript and XML)**는 **비동기적인 웹 애플리케이션**을 제작하기 위한 기법입니다.
	- 서버로부터 **필요한 데이터만 요청**하여 웹 페이지를 동적으로 업데이트합니다.
	- **JavaScript**와 **XMLHttpRequest** 객체를 이용해 서버와 데이터를 비동기적으로 주고받으며, 응답을 처리하기 위해 클라이언트 측에서 **JavaScript**가 사용됩니다.
	
	따라서, 괄호 안에 들어갈 정답은 **AJAX (Asynchronous JavaScript and XML)**입니다.









#### 5. 아래 내용을 확인하여 괄호 안에 용어를 표안에 알맞는 값을 고르시오.

| 구분    | 내용                                                                                                                                                                                                                                        |
|-------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| (   ) | - 회선교환 방식과 데이터그램 방식의 장점을 결합한 통신 기술이다.  <br>  <br> - 처음 패킷으로 최적의 경로를 고정하고 경로가 고정되면 그 다음은 패킷으로 나누어 고속으로 전송할 수 있다.  <br>  <br> - 통신기술에는 ATM이 있으며, 정해진 시간 안이나 다량의 데이터를 연속으로 보낼 때 적합하다.                                                        |

- 정답 및 해설
  - 정답 :
	1. **가상회선 (Virtual Circuit)**
	2. **데이터그램 (Datagram)**
  - 해설
	### 1. **가상회선 (Virtual Circuit)**:
	
	- **설명**:
	  - **가상회선**은 **회선 교환 방식**과 **데이터그램 방식**의 **장점을 결합한 통신 기술**입니다.
	  - 통신을 시작할 때 **처음 패킷으로 최적의 경로를 설정**하고, 이후 모든 패킷은 이 **고정된 경로**를 통해 전송됩니다. 이를 통해 **회선 교환의 안정성**과 **데이터그램의 효율성**을 결합합니다.
	  - **ATM (Asynchronous Transfer Mode)**이 이에 해당하며, **정해진 시간 안에** 많은 데이터를 전송해야 할 때 적합합니다.
	
	- **정답**: **가상회선 (Virtual Circuit)**
	
	### 2. **데이터그램 (Datagram)**:
	
	- **설명**:
	  - **데이터그램**은 **패킷 교환 방식**으로, 각 패킷이 **독립적으로 처리**되어 전송되는 방식입니다. **IP 주소**를 사용하여 인터넷에서 데이터를 전송합니다.
	  - 각 패킷은 **미리 정해진 경로 없이** 독립적으로 전송되며, **고정된 경로가 없습니다**.
	  - 특정 경로의 문제 발생 시 다른 경로를 통해 전송되기 때문에 **신뢰성**이 높으며, **가상회선과 달리** 경로의 장애에 대한 유연성이 큽니다.
	  - **짧은 메시지** 전송에 효과적이며, 전송된 패킷들을 올바른 순서로 **재정렬하는 기능**이 필요합니다.
	
	- **정답**: **데이터그램 (Datagram)**
	
	### 요약:
	
	- **가상회선 (Virtual Circuit)**: **회선교환**과 **데이터그램 방식**의 장점을 결합하여, **처음 경로를 고정한 후 고속으로 전송**하는 방식입니다. **ATM**과 같은 고속 전송이 필요할 때 적합합니다.
	- **데이터그램 (Datagram)**: 각 패킷이 **독립적으로 처리**되며, **고정된 경로 없이 전송**되는 방식으로 **IP** 주소를 사용하여 데이터를 전송합니다. **유연한 경로 설정**으로 신뢰성이 높습니다.
	
	따라서:
	
	1. **가상회선 (Virtual Circuit)**
	2. **데이터그램 (Datagram)**
	
	다시 한 번 혼란을 드린 점 사과드리며, 올바른 답변을 제공해드렸습니다.

	주어진 설명은 **2계층(데이터링크 계층)** 에서 동작하는 **터널링 기술**에 대한 설명입니다. 아래 각 설명에 맞는 답은 **L2TP (Layer 2 Tunneling Protocol)** 입니다.
	
	### L2TP에 대한 설명:
	
	1. **2계층에서 구현되는 터널링 기술**:
	   - **L2TP**는 **2계층(데이터링크 계층)** 에서 동작하는 **터널링 프로토콜**로, 가상 사설망(VPN) 연결을 제공하기 위해 사용됩니다.
	
	2. **L2F와 PPTP가 결합된 프로토콜**:
	   - **L2TP (Layer 2 Tunneling Protocol)** 는 **L2F (Layer 2 Forwarding Protocol)** 와 **PPTP (Point-to-Point Tunneling Protocol)** 의 기능을 결합한 프로토콜입니다.
	   - **L2F**는 시스코(Cisco)에서 개발되었고, **PPTP**는 마이크로소프트(Microsoft)에서 개발되었습니다. 이 두 프로토콜의 장점을 통합하여 **L2TP**가 개발되었습니다.
	
	3. **VPN 및 ISP에서 사용**:
	   - **L2TP**는 **VPN**(Virtual Private Network)을 제공하기 위해 널리 사용되며, 인터넷 서비스 제공자(ISP)에서도 많이 사용됩니다.
	
	4. **IPsec과 함께 사용**:
	   - **L2TP**는 **IPsec (Internet Protocol Security)** 와 함께 사용되면 PPTP보다 훨씬 **안전한 통신**을 제공합니다.
	   - **L2TP/IPsec** 조합은 PPTP에 비해 **더 높은 보안성**을 제공하며, 암호화 및 인증 기능을 강화할 수 있습니다.
	
	5. **보안보다는 익명성에 적합**:
	   - **L2TP**는 보안성보다는 **익명화**를 위해 더 적합한 프로토콜로, 데이터의 **익명성**을 보호하는 데 유용합니다.
	
	### 요약:
	
	- **L2TP (Layer 2 Tunneling Protocol)** 는 **2계층에서 동작하는 터널링 기술**로, **L2F와 PPTP의 장점을 결합**한 프로토콜입니다.
	- **VPN**을 제공하기 위해 널리 사용되며, 인터넷 서비스 제공자(ISP)에서도 활용됩니다.
	- **IPsec**과 함께 사용하면 PPTP보다 훨씬 **안전한 통신**을 제공하며, **익명화**에 적합한 프로토콜입니다.
	
	따라서, 정답은 **L2TP (Layer 2 Tunneling Protocol)** 입니다.

	### 코드 분석:
	
	```c

	int main() {
	    int input = 101110;
	    int di = 1;
	    int sum = 0;
	
	    while (1) {
	        if (input == 0) break;
	        else {
	            sum = sum + (input (a)(b)) * di;
	            di = di * 2;
	            input = input / 10;
	        }
	    }
	    printf("%d", sum);
	    return 0;
	}
	```
	
	이 코드의 목적은 이진수 **101110**을 **십진수**로 변환하는 것입니다. 아래 각 부분을 분석해 보겠습니다.
	
	#### 변수 설명:
	
	- **`input`**: 변환하고자 하는 **이진수**입니다. 초기 값은 **101110**입니다.
	- **`di`**: 현재 자리의 **2의 제곱 값**을 나타내며, 처음에는 **1**로 설정되어 있습니다.
	- **`sum`**: 변환된 **십진수의 합**을 저장하는 변수입니다. 초기 값은 **0**입니다.
	
	#### 반복문 (`while`) 분석:
	
	- **반복문 종료 조건**:
	  - `if (input == 0) break;`는 **입력값(input)** 이 0이 될 때 반복문을 종료합니다.
	
	- **이진수에서 각 자리의 숫자를 추출하는 부분**:
	  - **`input % 10`** 연산을 통해 이진수의 **가장 오른쪽 자리(1의 자리)** 값을 추출합니다.
	  - 예를 들어, `input = 101110`일 때, `input % 10`은 **`0`** 입니다.
	  
	  - 빈칸 **(a)**  들어갈 연산자는 **`%`** 이며, **(b)** 에는 **`10`** 이 들어갑니다. 따라서:
	    ```c
	    sum = sum + (input % 10) * di;
	    ```
	    - **`input % 10`** 은 **현재 자리의 비트 값**(0 또는 1)을 가져옵니다.
	    - **`* di`** 는 **현재 자리의 값을 2의 제곱과 곱하여** 해당 자리의 값을 십진수로 변환합니다.

	  - `input = input / 10;`은 **이진수에서 다음 자리로 이동**하기 위해 사용됩니다.
	  - 예를 들어, `input = 101110`일 때, `input / 10`은 **`10111`** 이 되어, 다음 반복에서 왼쪽 자리로 이동하게 됩니다.
	
	- **다음 자리의 `2의 제곱 값` 계산**:
	  - `di = di * 2;`는 **다음 자리**를 처리하기 위해 **2의 제곱 값**을 증가시킵니다.
	  - 처음에는 `di = 1`, 다음 반복에서는 `di = 2`, 그 다음은 `4`, `8`, 등으로 증가합니다.
	
	### 계산 과정:
	
	1. **초기 값**:
	   - `input = 101110`
	   - `di = 1`
	   - `sum = 0`
	
	2. **반복 과정**:
	   - **1차 반복**:
	     - `input % 10 = 0`
	     - `sum = sum + (0 * 1) = 0`
	     - `di = 1 * 2 = 2`
	     - `input = 101110 / 10 = 10111`
	   - **2차 반복**:
	     - `input % 10 = 1`
	     - `sum = 0 + (1 * 2) = 2`
	     - `di = 2 * 2 = 4`
	     - `input = 10111 / 10 = 1011`
	   - **3차 반복**:
	     - `input % 10 = 1`
	     - `sum = 2 + (1 * 4) = 6`
	     - `di = 4 * 2 = 8`
	     - `input = 1011 / 10 = 101`
	   - **반복이 계속되어 최종적으로 `sum = 46`이 됩니다.**
	
	### 최종 출력:
	
	- **십진수로 변환된 값**은 **46**입니다.

- 다른 무언가와 이어지는 인터페이스 역할을 하는 클래스를 의미한다.
  
- 실제 객체를 호출하면 행위를 중간에 가로채서 다른 동작을 수행하는 객체로 변경한다.
  
- 객체를 정교하게 제어해야 하거나 객체 참조가 필요한 경우 사용한다.
  
- 분리된 객체를 위임함으로써 대리 작업을 중간 단계에 삽입할 수도 있으며 분리된 객체를 동적으로 연결함으로써 객체의 실행 시점을 관리할 수도 있다.


- 정답 및 해설 :
  - 정답 :
    - **프록시 (Proxy) 패턴**
  - 해설 :
	주어진 설명은 **프록시(Proxy) 패턴** 에 대한 특징을 설명하고 있습니다. **프록시 패턴**은 **구조 패턴(Structural Pattern)** 의 한 종류입니다. 아래 각 설명을 분석하여 프록시 패턴에 해당하는지 확인하겠습니다.
	
	### 프록시(Proxy) 패턴:
	
	1. **"다른 무언가와 이어지는 인터페이스 역할을 하는 클래스를 의미한다."**:
	   - **프록시 패턴**은 **다른 객체에 대한 인터페이스 역할**을 수행합니다. 즉, 실제 객체에 접근하기 전에 이를 대리하는 객체를 제공하여 **객체에 대한 간접적인 접근**을 가능하게 합니다.
	
	2. **"실제 객체를 호출하면 행위를 중간에 가로채서 다른 동작을 수행하는 객체로 변경한다."**:
	   - **프록시 객체**는 **실제 객체의 호출을 가로채어** 추가적인 작업을 수행할 수 있습니다. 예를 들어, **접근 제어**, **로깅**, **캐싱** 등과 같은 작업을 프록시 객체에서 처리한 후 실제 객체에 접근하게 합니다.
	
	3. **"객체를 정교하게 제어해야 하거나 객체 참조가 필요한 경우 사용한다."**:
	   - **프록시 패턴**은 객체에 대한 **정교한 제어**가 필요한 경우 사용됩니다. 예를 들어, 객체에 대한 **접근 권한**을 제한하거나, **지연 로딩**(Lazy Loading)을 통해 객체가 필요할 때 생성하도록 하는 경우에 유용합니다.
	
	4. **"분리된 객체를 위임함으로써 대리 작업을 중간 단계에 삽입할 수도 있으며 분리된 객체를 동적으로 연결함으로써 객체의 실행 시점을 관리할 수도 있다."**:
	   - **프록시 객체**는 **대리 작업**을 수행하기 위해 사용되며, 실제 객체에 대한 호출을 **지연**하거나 **추가적인 로직을 삽입**할 수 있습니다. 이를 통해 객체의 실행 시점과 동작을 정교하게 제어할 수 있습니다.
	
	### 요약:
	
	- **프록시(Proxy) 패턴**은 **구조 패턴(Structural Pattern)**의 한 종류로, **실제 객체에 대한 접근을 제어하기 위한 대리 객체**를 사용하는 패턴입니다.
	- **프록시**는 실제 객체에 접근하기 전에 **중간에 다른 동작을 삽입**하거나 **추가적인 작업을 수행**할 수 있도록 합니다.
	- 이를 통해 **접근 제어, 로깅, 지연 로딩**과 같은 다양한 시나리오에서 객체를 **정교하게 제어**할 수 있습니다.
	
	따라서, 주어진 설명에 해당하는 디자인 패턴은 **프록시(Proxy) 패턴**입니다.

- SELECT절에 별칭을 사용하여 작성해야 한다.  
- SQL 구문 마지막에 세미콜론 생락 가능하다.  
- 반드시 GROUP BY와 having을 사용해야 한다.  
- 집계함수를 사용해야 한다.



- 정답 및 해설
  - 정답 :
```sql
select 
	과목이름 as 과목이름,
	점수 as 최소점수
```
  - 해설
	#### 정답:
	
	```sql
	SELECT  
	  과목이름  
	  ,MIN(점수) AS 최소점수  
	  ,MAX(점수) AS 최대점수  
	From   
	  성적  
	GROUP BY   
	  과목이름  
	HAVING  
	  AVG(점수) >= 90
	```
	
	#### 해설:
	
	주어진 문제는 **성적 테이블**에서 **과목 이름이 '데이터베이스'인 경우에 대한 최소 점수와 최대 점수**를 구하는 SQL을 작성하는 것입니다. 문제에서 주어진 조건을 만족하는 방식으로 SQL을 작성해 보겠습니다.
	
	### 조건 분석:
	
	1. **`WHERE` 사용하지 말 것**:
	   - `WHERE` 조건을 사용할 수 없으므로, 과목 이름이 '데이터베이스'인 경우는 **`HAVING`** 절에서 필터링해야 합니다.
	
	2. **`SELECT` 절에 별칭 사용**:
	   - `SELECT` 절에 **별칭 (Alias)** 을 사용해야 하므로, 최소 점수와 최대 점수 컬럼에 각각 **`AS 최소점수`, `AS 최대점수`** 를 붙입니다.
	
	3. **`GROUP BY`와 `HAVING` 사용**:
	   - **`GROUP BY`** 를 사용하여 **과목 이름별로 그룹화**하고, 특정 과목 이름에 대한 조건은 **`HAVING`** 절에서 필터링합니다.
	
	4. **집계 함수 사용**:
	   - **집계 함수**인 **`MIN`** 과 **`MAX`** 를 사용하여 최소 점수와 최대 점수를 구합니다.

	### SQL 설명: {id="sql_1"}
	
	- **`SELECT 과목이름, MIN(점수) AS 최소점수, MAX(점수) AS 최대점수`**:
	  - `과목이름`별로 **최소 점수**와 **최대 점수**를 구하여 출력합니다.
	  - `MIN(점수)`와 `MAX(점수)`를 각각 **`최소점수`**, **`최대점수`** 라는 **별칭**으로 출력합니다.
	
	- **`FROM 성적`**:
	  - **`성적`** 테이블에서 데이터를 가져옵니다.
	
	- **`GROUP BY 과목이름`**:
	  - **과목 이름**으로 그룹화하여 각 과목에 대해 최소 점수와 최대 점수를 구합니다.
	
	- **`HAVING 과목이름 = '90'`**:
	  - **`HAVING`** 절을 사용하여 **'90'** 점 이상에 해당하는 결과만 필터링합니다.
		
	### 최종 SQL:
	
	```sql
	SELECT  
	  과목이름  
	  ,MIN(점수) AS 최소점수  
	  ,MAX(점수) AS 최대점수  
	From   
	  성적  
	GROUP BY   
	  과목이름  
	HAVING  
	  AVG(점수) >= 90
	```
	
	### 출력 결과:
	
	- 이 SQL은 **과목 이름이 '데이터베이스'인 경우**에 대한 **최소 점수(89)** 와 **최대 점수(92)** 를 출력합니다.
	- 결과는 다음과 같습니다:

	| 과목이름     | 최소점수 | 최대점수 |
	| ---------- | ------- | ------- |
	| 데이터베이스 | 89      | 92      |
	
	이 쿼리는 문제에서 요구한 **모든 조건을 만족**합니다.

#### 19. 다음 아래 제어 흐름 그래프가 분기 커버리지를 만족하기 위한 테스팅 순서를 쓰시오.


![[2023 1회차 19번 문제.png]]



- 정답 및 해설
  - 정답 : `1234561`, `124567`  or `1234567`, `124561`
  - 해설 :
	
	주어진 **제어 흐름 그래프(Control Flow Graph)**에서 **분기 커버리지를 만족하기 위한 테스팅 순서**를 작성해야 합니다. **분기 커버리지**는 프로그램의 **모든 조건문에서 각 분기(참/거짓)마다 실행될 수 있도록 테스트 케이스를 만드는 것**입니다. 이를 통해 **모든 분기 조건**이 **한 번 이상** 실행되었는지 확인하는 것을 목표로 합니다.
	
	### 그래프 분석:
	
	- 그래프는 순서대로 각 조건과 실행 경로를 제시하고 있으며, 이를 다음과 같이 번호로 나타낼 수 있습니다.
	  1. **초기화 (`POINTER = FALSE`)**: 시작점에서 **`POINTER`**는 **`FALSE`**로 초기화됩니다.
	  2. **조건 `X > K` 확인**: 이 조건이 **참(YES)** 또는 **거짓(NO)**일 수 있습니다.
	  3. **참일 때 (`X > K`)**: **`POINTER`**를 **`TRUE`**로 설정합니다.
	  4. **거짓일 때 (`X <= K`)**: **`X`를 `X + 2`**로 업데이트합니다.
	  5. **`SUBX` 호출**: 함수 **`SUBX`**를 호출하고 결과를 저장합니다.
	  6. **`RESULT > 1` 확인**: 조건이 **참(YES)** 또는 **거짓(NO)**일 수 있습니다.
	  7. **출력(`PRINT RESULT`)**: `RESULT > 1`이 **거짓(NO)**인 경우 출력이 수행됩니다.
	
	### 분기 커버리지 만족을 위한 테스팅 경로:
	
	**분기 커버리지**를 만족하기 위해서는 각 분기 조건의 **참(True)**과 **거짓(False)** 모두를 테스트할 수 있어야 합니다. 따라서 그래프에서 모든 경로를 지나야 하므로, 다음과 같은 테스트 경로를 포함해야 합니다.
	
	1. **경로 1 → 2 (YES) → 3**:
	   - 이 경로는 **`X > K`**가 **참**일 때의 동작을 검사합니다.
	   - `POINTER`가 **`TRUE`**로 설정되며, 이후 종료됩니다.
	
	2. **경로 1 → 2 (NO) → 4 → 5 → 6 (YES)**:
	   - 이 경로는 **`X > K`**가 **거짓**일 때의 동작을 검사합니다.
	   - **`X`**를 **`X + 2`**로 업데이트한 뒤, 함수 **`SUBX`**를 호출하고 **`RESULT > 1`**이 **참**일 때의 동작을 검사합니다.
	
	3. **경로 1 → 2 (NO) → 4 → 5 → 6 (NO) → 7**:
	   - 이 경로는 **`X > K`**가 **거짓**일 때의 동작을 검사하며, 이후 **`RESULT > 1`**이 **거짓**일 때의 동작을 검사하고 **결과를 출력**합니다.
	
	### 테스트 경로 요약:
	
	- **경로 1**: `1 → 2 (YES) → 3`
	- **경로 2**: `1 → 2 (NO) → 4 → 5 → 6 (YES)`
	- **경로 3**: `1 → 2 (NO) → 4 → 5 → 6 (NO) → 7`
	
	### 해설:
	
	- **분기 커버리지**를 만족하려면 모든 조건문이 **참과 거짓** 두 가지 경우를 **최소 한 번씩** 검사해야 합니다.
	- **조건 1** (`X > K`)와 **조건 2** (`RESULT > 1`)에 대해 각각 **참과 거짓**을 모두 검사하는 경로를 포함해야 합니다.
	- 위의 **3개의 경로**를 테스트하면, **모든 분기 조건**이 **한 번 이상** 실행되므로 **분기 커버리지를 만족**하게 됩니다.
	
	따라서, 주어진 제어 흐름 그래프의 **분기 커버리지를 만족하기 위한 테스트 경로**는:
	
	- **`1 → 2 (YES) → 3`**
	- **`1 → 2 (NO) → 4 → 5 → 6 (YES)`**
	- **`1 → 2 (NO) → 4 → 5 → 6 (NO) → 7`**
	
	입니다.

  - 해설 :

	### 코드 분석:
	
	1. **`Parent` 클래스**:
	   ```java
	   class Parent {
	       int x = 100;
	
	       Parent() {
	           this(500);
	       }
	
	       Parent(int x) {
	           this.x = x;
	       }
	
	       int getX() {
	           return x;
	       }
	   }
	   ```
	   - **멤버 변수** `x`는 초기값으로 **`100`**이 설정되어 있습니다.
	   - **기본 생성자 `Parent()`**는 매개변수 하나를 받는 생성자 **`Parent(int x)`**를 호출합니다. 이때, **`500`**을 인자로 넘겨줍니다. 따라서 기본 생성자를 통해 객체가 생성될 때 **`x`**는 **`500`**으로 설정됩니다.
	   - **`getX()`** 메소드는 현재 **`x`**의 값을 반환합니다.
	
	2. **`Child` 클래스** (`Parent` 상속):
	   ```java
	   class Child extends Parent {
	       int x = 4000;
	
	       Child() {
	           this(5000);
	       }
	
	       Child(int x) {
	           this.x = x;
	       }
	   }
	   ```
	   - **`Child` 클래스**는 **`Parent` 클래스를 상속**합니다.
	   - **멤버 변수** `x`는 **`4000`**으로 초기화됩니다.
	   - **기본 생성자 `Child()`**는 **`Child(int x)`** 생성자를 호출하며, **`5000`**을 인자로 넘겨줍니다. 이로 인해 **멤버 변수 `x`**는 **`5000`**으로 설정됩니다.
	   - **중요**: 이 **`x`** 변수는 **`Child` 클래스에만 존재**하며, **`Parent` 클래스의 `x` 변수와는 별개의 변수**입니다.
	
	3. **`Main` 클래스 (`main` 메소드)**:
	   ```java
	   public class Main {
	       public static void main(String[] args) {
	           Child obj = new Child();
	           System.out.println(obj.getX());
	       }
	   }
	   ```
	   - **`Child obj = new Child();`**:
	     - **`Child` 클래스의 기본 생성자**가 호출됩니다.
	     - 기본 생성자 `Child()`는 **`Child(int x)`** 생성자를 호출하며, **`5000`**을 인자로 넘겨줍니다. 이에 따라 **`Child` 클래스의 `x`**는 **`5000`**으로 설정됩니다.
	     - 그러나 **`Parent` 클래스의 기본 생성자**도 호출되며, 이 생성자에서 **`Parent(int x)`** 생성자가 호출되고 **`x`**를 **`500`**으로 설정합니다.
	     - 이 **`x`**는 **`Parent` 클래스의 멤버 변수**입니다.
	
	   - **`System.out.println(obj.getX());`**:
	     - **`getX()`** 메소드는 **`Parent` 클래스에서 정의된 메소드**입니다.
	     - `obj`는 **`Child` 클래스의 인스턴스**이지만, **`getX()`** 메소드는 **`Parent` 클래스**에서 상속된 메소드입니다.
	     - **`Parent` 클래스의 `x` 변수**를 반환하며, 이는 **`500`**으로 설정되어 있습니다.
	
	### 요약:
	
	- **`Parent` 클래스의 `x`**는 **`500`**으로 설정되어 있고, **`Child` 클래스의 `x`**는 **`5000`**입니다.
	- **`getX()`** 메소드는 **`Parent` 클래스**에서 정의된 메소드이므로, **`Parent` 클래스의 `x`** 값을 반환합니다.
	- 따라서, **출력값**은 **`500`**입니다.
