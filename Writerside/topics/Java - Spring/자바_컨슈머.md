# 자바 컨슈머

자바에서 **Consumer**는 주로 **함수형 인터페이스**로 사용되며, `java.util.function` 패키지에 속해 있습니다. Consumer 인터페이스는 하나의 인자를 받아서 처리하지만, 결과를 반환하지 않는 특징을 가지고 있습니다. 아래에서 Consumer에 대해 자세히 설명하겠습니다.

---

### 1. Consumer 인터페이스란?

- **기능**:  
    Consumer는 단일 인자 `T`를 받아서 어떤 작업을 수행(소비, 처리)하지만, 결과값은 반환하지 않습니다. 주로 **부수 효과(side-effect)** 가 있는 작업(예: 출력, 로깅, 상태 변경 등)을 수행할 때 사용됩니다.
    
- **함수형 인터페이스**:  
    Consumer는 하나의 추상 메서드인 `accept(T t)`만을 가지고 있으며, 이를 통해 람다 표현식이나 메서드 레퍼런스로 쉽게 구현할 수 있습니다.
    
    ```java
    @FunctionalInterface
    public interface Consumer<T> {
        void accept(T t);
        
        default Consumer<T> andThen(Consumer<? super T> after) {
            Objects.requireNonNull(after);
            return (T t) -> { 
                accept(t); 
                after.accept(t); 
            };
        }
    }
    ```
    

---

### 2. 주요 메서드

- **`void accept(T t)`**  
    인자 `t`를 받아서 해당 객체에 대해 특정 작업을 수행합니다.
    
- **`default Consumer<T> andThen(Consumer<? super T> after)`**  
    현재 Consumer가 `accept` 메서드를 실행한 후, `after`로 전달된 다른 Consumer를 실행합니다.  
    이를 통해 여러 작업을 순차적으로 연결하여 처리할 수 있습니다.
    

---

### 3. 사용 예제

아래 예제는 List의 요소들을 순회하며 각 요소를 출력하는 Consumer를 사용한 코드입니다.

```java
import java.util.Arrays;
import java.util.List;
import java.util.function.Consumer;

public class ConsumerExample {
    public static void main(String[] args) {
        List<String> names = Arrays.asList("Alice", "Bob", "Charlie");

        // 람다식을 사용한 Consumer 구현: 각 이름을 출력
        Consumer<String> printName = name -> System.out.println("Name: " + name);

        // List의 각 요소에 대해 printName Consumer를 실행
        names.forEach(printName);

        // andThen을 사용한 Consumer 체이닝
        Consumer<String> printUpperCase = name -> System.out.println("UpperCase: " + name.toUpperCase());
        System.out.println("\n체이닝 예제:");
        names.forEach(printName.andThen(printUpperCase));
    }
}
```

**실행 결과:**

```
Name: Alice
Name: Bob
Name: Charlie

체이닝 예제:
Name: Alice
UpperCase: ALICE
Name: Bob
UpperCase: BOB
Name: Charlie
UpperCase: CHARLIE
```

---

### 4. 언제 사용하나요?

- **데이터 소비**:  
    데이터를 처리하면서 별도의 결과값을 반환하지 않고 단순히 소비하는 작업이 필요할 때 유용합니다. 예를 들어, 로그 출력이나 상태 업데이트 등.
    
- **forEach와 같은 메서드**:  
    컬렉션의 요소들을 순회하며 각 요소에 대해 작업을 수행할 때 Consumer를 자주 사용합니다. 예를 들어, `List.forEach(Consumer)` 메서드에서 활용됩니다.
    
- **함수형 프로그래밍**:  
    람다 표현식 및 메서드 레퍼런스와 함께 간결하고 직관적인 코드 작성을 지원하여 함수형 프로그래밍 패러다임을 구현할 때 유용합니다.
    

---

### 5. 추가 변형 인터페이스

Consumer 외에도 기본 자료형을 처리하기 위한 변형 인터페이스들이 존재합니다:

- `IntConsumer`
- `LongConsumer`
- `DoubleConsumer`

이들은 각각 `int`, `long`, `double` 타입의 값을 처리할 때 사용됩니다.

---

요약하면, **자바의 Consumer**는 입력값을 받아서 특정 작업(주로 부수 효과)을 수행하는 함수형 인터페이스로, 람다 표현식이나 메서드 레퍼런스를 사용하여 간결하게 구현할 수 있으며, 여러 작업을 순차적으로 수행하기 위해 `andThen` 메서드를 통해 체이닝할 수 있습니다.
