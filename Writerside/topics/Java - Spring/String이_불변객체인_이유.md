# String이 불변객체인 이유


1. 성능
    1. 문자열은 상수 풀에 등록 된다.
     2. 문자열이 있다면 상수 풀에서 해당 문자열을 가지고 오고, 없다면 상수 풀에 등록하고 해당하는 레퍼런스 값을 반환한다.
2. 동기화
    1. 불변 객체는 값이 바뀔 일이 없기 때문에 멀티스레드 환경에서 Thread-safe하다는 장점이 있음.
3. 해시코드 캐싱
    1. String의 해시코드 메서드는 hash값을 계산한 적이 없을 때에 최초 1번만 실제 계산 로직을 수행하고, 이후부터는 caching이 되어 있음.
4. 보안
    1. url같은것 바뀌면 안됨.
