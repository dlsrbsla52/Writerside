# 스프링 빈 생명주기

스프링 빈(Spring Bean)의 생명주기는 스프링 IoC 컨테이너에 의해 관리되는 동안 빈이 겪는 일련의 단계를 의미합니다. 스프링 빈의 생명주기는 다음과 같은 단계로 구성됩니다:

### 1. 인스턴스화 (Instantiation)

스프링 컨테이너는 빈의 정의(클래스 정보, 스코프, 기타 설정)를 바탕으로 빈의 인스턴스를 생성합니다. 이 단계는 기본적으로 `new` 키워드를 사용하여 빈 객체를 생성하는 것과 같습니다.

### 2. 의존성 주입 (Dependency Injection)

빈이 인스턴스화된 후, 스프링 컨테이너는 빈에 필요한 의존성을 주입합니다. 의존성 주입은 생성자 주입, 세터 주입, 또는 필드 주입을 통해 이루어질 수 있습니다. 이를 통해 빈의 의존 관계가 설정됩니다.

### 3. 빈 초기화 (Initialization)

빈이 생성되고 의존성이 주입된 후, 빈의 초기화 단계가 진행됩니다. 이 단계에서는 빈이 초기화 작업을 수행할 수 있습니다. 스프링은 이를 위해 두 가지 메커니즘을 제공합니다:

- **InitializingBean 인터페이스**: 빈 클래스가 `org.springframework.beans.factory.InitializingBean` 인터페이스를 구현하고 `afterPropertiesSet()` 메서드를 오버라이드하면, 스프링 컨테이너는 빈 초기화 시 이 메서드를 호출합니다.
- **init-method 속성**: XML 설정이나 `@Bean` 애노테이션의 `initMethod` 속성을 사용하여 초기화 메서드를 지정할 수 있습니다.
- **@PostConstruct 애노테이션**: JSR-250 표준 애노테이션으로, 초기화 메서드를 지정할 수 있습니다.

### 4. 빈 사용 (Bean Usage)

빈이 초기화된 후, 애플리케이션은 빈을 사용합니다. 애플리케이션 컨텍스트에 의해 빈이 관리되며, 애플리케이션 내에서 빈의 메서드를 호출하여 비즈니스 로직을 수행합니다.

### 5. 빈 소멸 (Destruction)

애플리케이션 컨텍스트가 종료되거나 빈이 더 이상 필요하지 않으면, 빈의 소멸 단계가 진행됩니다. 이 단계에서는 빈이 정리 작업을 수행할 수 있습니다. 스프링은 이를 위해 두 가지 메커니즘을 제공합니다:

- **DisposableBean 인터페이스**: 빈 클래스가 `org.springframework.beans.factory.DisposableBean` 인터페이스를 구현하고 `destroy()` 메서드를 오버라이드하면, 스프링 컨테이너는 빈 소멸 시 이 메서드를 호출합니다.
- **destroy-method 속성**: XML 설정이나 `@Bean` 애노테이션의 `destroyMethod` 속성을 사용하여 소멸 메서드를 지정할 수 있습니다.
- **@PreDestroy 애노테이션**: JSR-250 표준 애노테이션으로, 소멸 메서드를 지정할 수 있습니다.

### 예제 코드

다음은 스프링 빈의 생명주기를 보여주는 예제 코드입니다.

```java

import javax.annotation.PostConstruct;
import javax.annotation.PreDestroy;
import org.springframework.beans.factory.InitializingBean;
import org.springframework.beans.factory.DisposableBean;
import org.springframework.stereotype.Component;

@Component
public class MyBean implements InitializingBean, DisposableBean {

    // 빈의 초기화 메서드
    @PostConstruct
    public void postConstruct() {
        System.out.println("MyBean is being initialized using @PostConstruct");
    }

    @Override
    public void afterPropertiesSet() throws Exception {
        System.out.println("MyBean is being initialized using InitializingBean.afterPropertiesSet()");
    }

    // 빈의 소멸 메서드
    @PreDestroy
    public void preDestroy() {
        System.out.println("MyBean is being destroyed using @PreDestroy");
    }

    @Override
    public void destroy() throws Exception {
        System.out.println("MyBean is being destroyed using DisposableBean.destroy()");
    }
}

```

스프링 부트 애플리케이션 설정:

```java

import org.springframework.boot.CommandLineRunner;
import org.springframework.boot.SpringApplication;
import org.springframework.boot.autoconfigure.SpringBootApplication;
import org.springframework.context.annotation.Bean;

@SpringBootApplication
public class LifecycleExampleApplication {

    public static void main(String[] args) {
        SpringApplication.run(LifecycleExampleApplication.class, args);
    }

    @Bean
    public CommandLineRunner commandLineRunner() {
        return args -> {
            System.out.println("Application has started.");
        };
    }
}

```

### 실행 결과

애플리케이션이 시작되고 종료될 때, 다음과 같은 메시지가 출력됩니다.

```csharp

MyBean is being initialized using @PostConstruct
MyBean is being initialized using InitializingBean.afterPropertiesSet()
Application has started.
MyBean is being destroyed using @PreDestroy
MyBean is being destroyed using DisposableBean.destroy()

```

이 예제는 스프링 빈의 생명주기 각 단계를 보여줍니다. `MyBean` 클래스는 `InitializingBean`과 `DisposableBean` 인터페이스를 구현하여 초기화 및 소멸 메서드를 정의하고, `@PostConstruct`와 `@PreDestroy` 애노테이션을 사용하여 추가적인 초기화 및 소멸 메서드를 정의합니다. 애플리케이션 컨텍스트에 의해 빈이 생성되고 소멸되는 과정을 통해 빈의 생명주기를 확인할 수 있습니다.
