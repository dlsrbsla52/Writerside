


# TMS 이슈


### 1. LaTeX To HWP 문서 수식 변환

##### 내용
**tms-admin-client 처리 방식** 
> 1. 클라이언트에서 html변환 클릭
> 2. 해당하는 문제 파일을 .hml[^1]  파일(temp)로 저장
> 3. .hml 파일을 읽은 후 hwp 수식 문자열을 LaTeX 문자열로 변환
> 4. Web View에 변환한 LaTeX 문자열 노출



##### 처리 방식
**tms-admin-client 처리 방식 설계** 
> 1. Web View에 있는 Html(LaTex)[^2] 을 text로 넘김
> 2. 텍스트로 넘겨받은 데이터를 .replace() 해서 문자열 변환
