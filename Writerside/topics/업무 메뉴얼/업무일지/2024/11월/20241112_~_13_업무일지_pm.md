### 1. LaTeX To HWP 문서 수식 변환

##### 내용
**tms-admin-client 처리 방식** 
> 1. 클라이언트에서 html변환 클릭
> 2. 해당하는 문제 파일을 .hml[^1]  파일(temp)로 저장
> 3. .hml 파일을 읽은 후 hwp 수식 문자열을 LaTeX 문자열로 변환
> 4. Web View에 변환한 LaTeX 문자열 노출



##### 처리 방식
**tms-admin-client 처리 방식 설계** 
> 1. Web View에 있는 Html(LaTex)[^2] 을 text로 넘김
> 2. 텍스트로 넘겨받은 데이터를 .replace() 해서 문자열 변환


##### 진행 상황
1. 레이텍 문자 일부분 변환성공
2. 한글 수식 삽입 성공
3. 치환되지 않는 문자열 보정 작업 필요
4. 치횐되지 않는 문자열을 보정하는 작업이 너무 오래걸리고 명확하지 않다는 문제 발생
5. 구글링 검색 결과 MathMl을 사용하여 수식을 집어넣을 수 있다는 사실을 확인
6. 테스트 진행
7. 테스트 실패 지원되지 않음
8. 치환되는 문자열을 map에 넣고 검사를 통해 replace 루프를 줄임
9. 상진 팀장님 소스 개발 후 모듈 테스트 진행 대기
