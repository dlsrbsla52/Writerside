### 1. LaTeX To HWP 문서 수식 변환

##### 내용
**tms-admin-client 처리 방식** 
> 1. 클라이언트에서 html변환 클릭
> 2. 해당하는 문제 파일을 .hml[^1]  파일(temp)로 저장
> 3. .hml 파일을 읽은 후 hwp 수식 문자열을 LaTeX 문자열로 변환
> 4. Web View에 변환한 LaTeX 문자열 노출



##### 처리 방식
**tms-admin-client 처리 방식 설계** 
> 1. Web View에 있는 Html(LaTex)[^2] 을 text로 넘김
> 2. 텍스트로 넘겨받은 데이터를 .replace() 해서 문자열 변환

### 2. 빅쿼리 업로드 배치 요청
```
1. 333 프로모션 타겟 대상

테이블명 : TB_POINT_EXHAUSTION_EVENT_LOGIN_TARGET

  

select T.user_id

, MEM.mem_group

, CASE WHEN T.pay_point >= 30000 THEN 'A' ELSE 'B' END AS target_group

, T.reg_dt

from TB_POINT_EXHAUSTION_EVENT_LOGIN_TARGET AS T WITH(NOLOCK)

inner join dbo.tb_member as mem with(nolock)

on t.user_id = mem.user_id

where T.user_id not in (select user_id from dbo.tb_zocbo_staff)

and T.pay_point > 0

and T.reg_dt < @기준일

order by T.idx;

  

  

2. AB test 타겟 대상

테이블명 : TB_AB_TEST_TARGET  

  

SELECT user_id  
, mem_group  
, target_group  
, reg_dt  
FROM (  
SELECT MEM.user_id  
, MEM.mem_group  
, CASE WHEN T.user_id IS NOT NULL THEN 'B' ELSE 'A' END AS target_group  
, (SELECT MIN(Date_Login) From DBO.tb_MemberLoginHistory where user_id = MEM.user_id) AS reg_dt  
FROM DBO.TB_MEMBER AS MEM WITH(NOLOCK)  
INNER JOIN TB_AB_TEST_TARGET AS T WITH(NOLOCK)  
ON MEM.user_id = T.user_id  
WHERE MEM.user_id >= 5739967  
AND MEM.user_id NOT IN (SELECT user_id FROM DBO.TB_ZOCBO_STAFF)  
) AS AA  
WHERE reg_dt < @기준일
```
