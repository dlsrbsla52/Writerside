### 데이터 정합성 문제
데이터 정합성 이슈로 동일 날짜에 같은 디바이스로 접근 했음에도 CID의 수가 사용한 디바이스의 수보다 현저하게 많음

#### 확인 사용 쿼리 
```
SELECT USER_ID, COUNT(DISTINCT CID)
FROM `zocbodb.data.TB_TRACKING_LOG_202409`
WHERE USER_ID = 463567 AND REG_DT_YMDHMS > '20240101000000'
  AND OS_TYPE IN ('MAC', 'ios', 'ANDROID')
GROUP BY USER_ID
```
#### 결과

| USER_ID | CID(COUNT) |
| ------- | ---------- |
| 463567  | 27         |

#### 원인
앱에서 데이터 발송시 CID를 zocbo.com에서 계속 요청하는 현상으로 데이터 정합성에 문제를 미침

#### 해결 방안
앱에서 데이터 정합성 보존하여 트레킹 서버로 데이터 발송
