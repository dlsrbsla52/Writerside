# 22-07 ~ 22-09) 시험지 추출 기준 변경 프로세스 개발

기존 기출 서비스의 경우 학년, 학기, 과목 등의 메타 데이터를 통해 문항을 추출하여 서비스 하고 있었습니다.

새로운 문항 추출을 기준으로 서비스를 오픈 하기 위해 유사한 문항을 찾아 추출하는 서비스를 개발하기로 했습니다. 하지만 유사한 문항을 추출하려면 그에 맞는 메타 데이터가 필요했고 기초 메타 데이터를 쌓기 시작했습니다.

팀원이 개발한 API를 통해 문항을 전달하면 각 문항의 백터값을 가지고 새로운 메타 데이터를 쌓고 이를 통해 유사한 문항을 추출하는 프로세스를 개발 하였습니다.
