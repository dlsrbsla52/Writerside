# 24-03 ~ 24-06) 시험지, 정답지 분리 시스템 개발

족보 닷컴 시스템은 2009년부터 개발되어 문제 은행 시스템으로 진화하면서 많은 변화를 겪었습니다. 회원과 결제를 담당하는 데이터베이스(DB)와 문항을 담당하는 DB가 이원화되었으며, 족보 닷컴에서 문제 은행으로 파라미터를 전송하려면 기초 데이터가 필요했고, 시즌 중에는 약 20만 건의 행(row)을 처리해야 했습니다.

데이터 동기화 시스템을 개발하기 위해 선결되어야 할 조건은 다음과 같았습니다:

1. 빠른 처리량
2. 안정성

이 조건들을 만족시키기 위해 DB에서 데이터를 추출한 후 파일로 변환하여 S3에 저장하고, 각 DB에 시간별로 적재하는 방식으로 구현을 시작했습니다. 그러나 예외 상황은 항상 발생할 수 있기에, 각 시스템의 데이터를 적재하고 변환하는 과정을 코드로 분류하여 예외 발생 시 효율적으로 처리할 수 있도록 설계했습니다.

**프로젝트를 진행하면서 느낀 점**

1.데이터 동기화의 중요성 족보 닷컴 시스템의 핵심은 전국 학원의 학교 시험지 데이터를 기반으로 한 서비스 제공입니다. 이를 위해 각 학교, 학년, 학기, 과목 등의 정보를 메타데이터화 하여 언제든지 조건에 맞게 데이터를 추출하고 고객에게 제공하는 시스템을 구축해야 했습니다. 이러한 데이터 동기화 작업은 시스템의 신뢰성과 정확성을 높이는 데 매우 중요했습니다.

2.효율적인 데이터 관리 기초 데이터를 효과적으로 관리하고 동기화하는 시스템을 구축하면서, 데이터 관리의 효율성을 높이는 방법을 고민했습니다. 파일 변환 및 적재 방식을 통해 데이터 동기화 과정을 최적화하고, 이를 통해 시스템의 전반적인 성능을 향상시킬 수 있었습니다.

이번 프로젝트는 데이터 동기화와 성능 최적화, 예외 처리의 중요성을 깨닫게 해준 소중한 경험이었으며, 향후 더 복잡한 프로젝트에서도 이러한 경험을 바탕으로 성공적으로 수행할 자신감을 얻게 되었습니다.
