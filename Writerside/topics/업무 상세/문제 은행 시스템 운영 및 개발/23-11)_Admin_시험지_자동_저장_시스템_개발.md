# 23-11) Admin 시험지 자동 저장 시스템 개발

.net framework(wpf)로 제작한 window application에서 문항을 추출하고 시험지로 엮는 과정 중 실수로 시험지 초기화나 다른 문제로 덮어 썻을 때 이전으로 돌아가는 기능을 개발 했습니다.
하지만 현업에선 이것만으론 부족하다고 느꼇고 1분에 한번씩 자료구조를 만들고 데이터 구조가 이전과 달라지면 스택에 저장하고 그렇지 않으면 저장하지 않는 로직을 개발 했습니다.

이벤트는 델리게이트 이벤트를 통해 다른 쓰레드에서 작업하여

이전으로 돌아가기 버튼이나 ctl + z 를 누르면 스택에서 저장된 자료 구조를 불러와 다시 적용시킬 수 있었습니다.
